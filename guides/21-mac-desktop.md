## 跟着做：6 步完成一次练习

1. **操作 1：**从 Meta 官方下载页面进入 macOS 应用下载，不运行未知脚本和安装包。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

2. **操作 2：**安装时记录系统弹出的文件夹、日历、辅助功能或其他请求；不同 macOS 版本界面可能不同。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

3. **操作 3：**只提供一个专门新建的非敏感测试目录，放三份标有 TEST 的虚拟文档。不要先授权整个桌面和下载目录。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

4. **操作 4：**要求 Muse 生成文件命名计划和变更预览，明确不实际移动、重命名或删除。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

5. **操作 5：**人工确认原文件数量、修改前后命名映射；只在已核实产品权限后考虑写入测试目录。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

6. **操作 6：**完成后在 macOS 系统设置和 Muse 连接器页面分别检查授权，移除不再需要的权限，验证实际撤销。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

## 红队审核：容易踩的 4 个坑

1. 把 macOS 文件访问授权成整个磁盘，导致意外读取。
2. 认为“仅在聊天中让它不要删除”就足以覆盖操作系统权限。
3. 自动修改原件后没有记录 diff、无法回滚。
4. 把第三方数据当作个人信息未经同意处理。
