## 跟着做：6 步完成一次练习

1. **操作 1：**先明确可接受的商品规格、含税预算、售后、地区和服务范围。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

2. **操作 2：**让 Muse 仅检索公开商家页面，返回三项选项的现价、发布时间或查看日期、运费、退货条款。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

3. **操作 3：**购买前检查收货人、地址披露对象、数量、总价、支付渠道。Meta 官方介绍一次性卡号方案，这是平台设计陈述，不构成个人交易零风险保证。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

4. **操作 4：**如涉及 Marketplace 买卖，明确不自动向陌生人发送家庭住址或联系方式，先生成谈判草稿，所有对外动作逐次审批。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

5. **操作 5：**对于退货或退款，先核实原商家政策，生成客服草稿与凭证清单，不提交新的退货申请或争议。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

6. **操作 6：**确认订单是否成立时，必须进入商家原始系统核对订单号、交易状态和退款金额，不接受 Agent 自述作为凭证。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

## 红队审核：容易踩的 4 个坑

1. 使用已授权的长期“始终允许”，自动执行出价或透露位置。
2. 商品优惠价格与结算总价不一致。
3. 将 Meta 声明的一次性支付卡当作全部资金风险的保险。
4. 重复重试导致多次购买或产生售后争议。
