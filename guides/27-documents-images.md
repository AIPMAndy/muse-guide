## 跟着做：6 步完成一次练习

1. **操作 1：**选择一个可公开的主题，设定受众、信息来源、文件结构和画面需求。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

2. **操作 2：**从 Meta 官方功能页核对文档、图片生成是公开产品能力说明；具体导出格式仍须以账号 UI 为准。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

3. **操作 3：**先创建结构化文章提纲和事实清单，关键数字逐项核验原始来源。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

4. **操作 4：**图片生成要求原创视觉构成和版权合规，不模仿他人的商标标识或生成未经授权的真实人物形象。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

5. **操作 5：**生成之后人工检查文件是否能打开、格式是否一致、字体与移动端阅读是否完整。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

6. **操作 6：**对外发布前确认内容合规、商业披露与客户授权；最终发布时间和投放平台由人控制。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

## 红队审核：容易踩的 4 个坑

1. 图片很好看但文案引用虚构统计。
2. 只得到聊天回复却没有真实可打开的文件。
3. 把图像生成与商业平台版权授权等同看待。
4. 草稿中夹带客户姓名、内部报价或合同内容。

## 验收标准：必须留下证据
