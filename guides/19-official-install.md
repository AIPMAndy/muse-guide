## 学习目标

在不依赖非官方安装包、不授权私人账户的前提下完成一次公开资料任务。

**Meta 官方依据：**[访问对应原始官方页面](https://ai.meta.com/muse/download/)。

**重要边界：**官方展示某项能力不等于当前国家、设备或账号已经开放；操作界面、授权按钮、套餐与可用性以你真实账号为准。本教程没有访问你的 Muse 账号，以下步骤是可复现的教学方案，不声称已经执行成功。

## 跟着做：6 步完成一次练习

1. **操作 1：**从 Meta 官方 Muse 产品页进入 Download；优先打开 https://ai.meta.com/muse/download/。不要从第三方网盘下载所谓破解版。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

2. **操作 2：**核对当前设备是 iPhone、Android 还是 Mac。官方页面列出了这三类客户端；页面没有提供的系统入口应记为未确认。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

3. **操作 3：**记录下载页当前显示的版本号、安装来源、是否要求登录、所在地区及是否出现资格限制。不要将别人的截图当作自己账号的可用证明。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

4. **操作 4：**安装后使用合法拥有的个人账号完成官方登录和提示；不要在 Muse 聊天窗口直接输入密码、验证码或恢复码。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

5. **操作 5：**第一次只做公开检索：列出官方某项政策最近三份资料的链接和日期，不开启邮箱、支付、联系人连接器。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

6. **操作 6：**人工打开至少一条来源确认内容与日期相符，并记录任务开始/完成时间、失败提示及是否需要重试。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

```text
【完成报告】实际完成的动作、原始来源和日期、未完成项、待我批准的步骤、反方质疑、核验第三方状态的方法。

```

## 红队审核：容易踩的 4 个坑

1. 在搜索引擎结果中点击仿冒的下载站，上传真实账户凭证。
2. 把“官网列出 Mac 客户端”理解成“我所在地区一定有下载资格”。
3. 把回答里有链接误判为任务完成，未打开真实来源。
4. 因登录或地区限制反复尝试非官方绕过路径。
