## 跟着做：6 步完成一次练习

1. **操作 1：**先区分预算分析、订阅盘点、交易/支付、投资建议四种风险级别；第一次仅用虚构账单示例。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

2. **操作 2：**把样例收支分为固定支出、可变支出和一次性项目，明确分类口径和月份。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

3. **操作 3：**针对订阅费用，只用自己已审查并脱敏的账单摘要找重复扣费，不授权读取全部邮件或支付记录。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

4. **操作 4：**生成取消订阅候选清单，列平台、续费日和取消路径；不让 Agent 直接修改付费设置。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

5. **操作 5：**如需连接金融机构，先审查连接器真实权限、隐私条款和地区法律；非必要不连接高敏账户。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

6. **操作 6：**把节省金额计算设为“经验证的实际取消金额”，将预计金额、已执行金额、失败项严格区分。
   - **必须记录：**日期 / 当前客户端与账号前提 / 实际动作 / 原始证据 / 是否完成。

## 红队审核：容易踩的 4 个坑

1. 把预算建议写成经过验证的个人账单记录。
2. 根据不完整发票推断用户真实资产或负债。
3. 未经授权取消服务，导致数据或会员权益丢失。
4. 混淆预计节省、实际节省与已入账退款。

## 验收清单：必须留下证据

- [ ] 所有金额来自所提供样例和明确公式
- [ ] 订阅变更状态通过原始渠道确认
- [ ] 没有连接非必要银行、信贷或支付数据
- [ ] 完成时间与人工复核时间分开记录，并留下可以复现的输入摘要。
- [ ] 如未完成，明确记录失败原因、是否实际产生外部副作用和下次最小修复动作。

## 反证检查

主动寻找足以证明本次回答有误的证据：是否使用了过期信息、是否属于不开放的地区或账号、是否在第三方系统确实产生了外部动作。没有查到可靠证据时保持“未验证”。
