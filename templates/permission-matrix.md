# 连接器最小权限矩阵

| 系统 | 场景与业务目的 | 数据分类 | 当前权限（实测） | 所需最低权限 | 写入/共享审批 | 到期与撤销 |
|---|---|---|---|---|---|---|
| 示例：测试邮箱 | 起草回复 | 一般内部 | 未接入 | 指定标签只读 | 禁止发送 | 用后撤销 |
| ... | | | | | | |

## 操作前核验

- [ ] 当前 Muse 账户确实可见该连接器
- [ ] 用户有权授权目标数据（包括其他人的数据）
- [ ] 可用只读范围替代全账户写权限
- [ ] 是否存在“始终允许”、持久化或长期后台任务
- [ ] 撤销连接器后到第三方服务再次核对真实状态
- [ ] 任何授权变更都记录日期、操作者和理由

注意：提示词中的“禁止”不能代替系统层面的真实权限。
