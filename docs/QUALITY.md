# 可重复质量门禁

1. 文档：主题相互区分，写明适用范围、步骤、反证与验收标准。
2. 可验证：官方陈述与媒体报道分开引用；报价、地区和订阅不写死。
3. 链接：每个站内资源、首页锚点、章节路径都能在源码找到。
4. 技术：GitHub Actions 跑 Python `unittest`、JSON 格式与 JavaScript 语法测试。
5. 安全：本站不加载第三方 JS，不使用用户输入构造不可信 HTML，不上传任何表单到后端。
6. 无障碍：键盘可操作，按钮有语义，移动端有固定联系栏，尊重减少动画偏好。
7. 真实性：没有真实登录账号的动作不能宣称“我已替你测试/购买/发送”。
8. 发布：只在 Actions `test`、`deploy` 两项成功后写“站点上线成功”。
9. 剩余不确定性：实际浏览器端到端、移动设备和真实 Meta Muse 账户操作另行验证。
