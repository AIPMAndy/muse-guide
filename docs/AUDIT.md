## 四种必要证据

**O 官方宣称**、**I 独立报道**、**T 可复现账户测试**、**E 编辑建议**；只有附范围、日期、证据的条目才能从 E 提升至 T。不能用统计分数证明“全网第一”。

## 改动后的验收闸门

1. 本地页面依赖文件存在，内部跳转可用。
2. 结构化内容完整且 ID 不重复。
3. 公开安全事故、官方源、事实限制能被检索。
4. 联系方式一致，站点不引入外部脚本追踪。
5. GitHub Actions 测试及 Pages 部署执行成功。
6. **尚缺**跨设备端到端浏览器测试、真实 Muse 登录操作及竞品覆盖对比——后续通过社区实证迭代。

## 保留的风险与技术债

没有直接的 Meta Muse 真实账号操作凭证，不能宣称“所有教程都已逐步实测”。没有完整市场竞品库，不能宣称已经客观达到“全网最全”；当前目标是高覆盖度和可维护性。
