# Muse 产品家族不要混淆

| 名称 | 类型 | 典型入口 | 主要适用 |
|---|---|---|---|
| **Muse（个人 Agent）** | 消费端/个人 AI 代理 | [Meta Muse 官方介绍](https://ai.meta.com/muse/)、[muse.ai](https://muse.ai/) | 经授权跨应用处理日常任务 |
| **Muse for Small Business** | 面向小企业的能力与连接器集合 | [官方介绍](https://about.fb.com/news/2026/09/introducing-muse-small-business/) | 内容、业务跟进与协作范式 |
| **Muse Code** | 开发者编码 Agent | [Meta 开发者帮助](https://dev.meta.ai/help/subscriptions/what-is-a-muse-code-subscription) | 代码编写、终端式工作流 |
| **Muse Wonder / Wonder Full** | 模型家族 | [Meta 2026-10 公告](https://about.fb.com/news/2026/10/introducing-muse-wonder-models/) | 开发者/API/特定订阅渠道，逐步进入其他产品 |

**核查原则**：消费端订阅不能直接套 Muse Code 的 API 或 CLI 价格。模型公布或基准指标领先不等于当前每个 Muse 用户都有该模型。地区、客户端和订阅权益需登录真实官方账户确认。

2026-10-21 核查。信息可能变化，不能将本表视为长期固定的价格承诺。
