## 每项账户实测必须补的 8 个字段

1. 日期时间和国家/地区；设备（Web / iOS / Android / Mac / WhatsApp）。
2. 产品入口和版本（官方域名或客户端，不粘贴会话 Token）。
3. 账号是否具有该功能；灰度资格与套餐状态的实际屏幕证据（必须脱敏）。
4. 具体使用条件、连接器权限及系统“始终允许”设置。
5. 最短复现步骤、测试输入、预期结果。
6. 实际结果，以及是否在外部平台发生写入动作。
7. 是否可以停止、撤销、回滚以及独立复核。
8. 失败类型、误差/副作用与复查日期。

## 未确认并不代表功能不存在

本仓库**没有登录你或任何贡献者的 Meta Muse 账户**，不会宣称完成了真实下单、订阅取消、发邮件、移动文件或测试账号授权。官方宣布的功能可能因国家/设备/用户资格/更新时间而不可用。

## 有意不写死的动态信息

实时套餐价格、用量上限、国家开放表、具体按钮文案、API 能力及版本切换时间。未来仅引用来源明确、日期与适用人群具体的材料。

## 容易混淆的概念

Meta Muse 个人 AI Agent、Muse Code 编码助手、Muse Wonder 模型等属于不同产品渠道，不能拿其中某一个的价格、权益、功能和权限证明另一个已具备。
