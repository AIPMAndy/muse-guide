## 指标与误差

- **任务成功率** = 达到事前验收标准的任务数 / 尝试任务数，必须披露样本量。
- **事实准确率** = 已查证正确的事实条数 / 抽查事实条数；不能用带链接数代替正确率。
- **净节约时间** = 人工基线 -（Agent 配置时间 + 操作等待 + 复核 + 返工）。
- **有风险外部动作率** = 发生未经预期外部写入的任务数 / 涉及外部系统的任务数。
- **不确定性**：至少区分首次成功与重复成功，避免仅公开好案例造成选择偏差。

避免在此仓库上传包含真实姓名、联系地址、Token、客户保密资料的原始日志。
